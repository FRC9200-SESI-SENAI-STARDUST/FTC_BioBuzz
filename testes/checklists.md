# Checklists

Checklist não substitui conhecimento. Ele protege o conhecimento quando faltam cinco minutos, três pessoas perguntam coisas diferentes e a memória começa a cortar caminho.

## Antes de ligar

- [ ] Robô apoiado com segurança no primeiro teste
- [ ] Bateria carregada e presa
- [ ] Polaridade conferida
- [ ] Chave principal acessível
- [ ] Cabos longe de partes móveis
- [ ] Rodas e mecanismos giram livres à mão
- [ ] Área ao redor limpa
- [ ] Pessoa pronta para desligar

## Antes do treino

- [ ] Configuração correta no Robot Controller
- [ ] Versão correta do código instalada
- [ ] IMU inicializada e heading coerente
- [ ] Webcam reconhecida
- [ ] Encoders mudam no sentido esperado
- [ ] Limit switches respondem
- [ ] Contador de elementos zerado ou corrigido
- [ ] Auto selecionado e confirmado
- [ ] Telemetria sem falha ativa

## Antes de cada partida

- [ ] Bateria trocada e medida
- [ ] Conectores pressionados e presos
- [ ] USB protegido
- [ ] Parafusos marcados não se moveram
- [ ] Correias e correntes tensionadas
- [ ] Rodas sem dano
- [ ] Intake livre
- [ ] Shooter gira sem contato
- [ ] FLOWER recolhe dentro do envelope
- [ ] Elementos iniciais conferidos
- [ ] Aliança, lado e auto corretos
- [ ] Controles revisados com pilotos

## Após cada partida

- [ ] Desligar antes de tocar na elétrica
- [ ] Anotar falhas enquanto ainda estão frescas
- [ ] Conferir temperatura de motores e Hubs
- [ ] Procurar cabo solto, pó e marca de impacto
- [ ] Revisar contador e sensores
- [ ] Salvar log da partida
- [ ] Criar tarefa com responsável e prazo

## Validação de mecanismo

- [ ] Possui batente físico quando necessário
- [ ] Possui timeout
- [ ] Possui estado seguro
- [ ] Pode ser operado manualmente no pit
- [ ] Pode ser removido sem desmontar metade do robô
- [ ] Passou por pelo menos 20 repetições
- [ ] Foi testado com bateria forte e fraca
- [ ] Foi testado após impacto controlado

## Validação de software

- [ ] Código compila limpo
- [ ] Nenhuma porta ou constante crítica está escondida no OpMode
- [ ] Sensores possuem debounce ou validação
- [ ] Ângulos fazem wrap corretamente
- [ ] Não existe comparação exata com valor analógico
- [ ] Estados possuem timeout
- [ ] Falhas aparecem na telemetria
- [ ] Modo manual respeita limites críticos
- [ ] O robô para de forma segura ao encerrar o OpMode
